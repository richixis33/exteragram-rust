# ⚡ exteraGram Rust Mobile

<p align="center">
  <b>Современный мобильный клиент Telegram с ядром на Rust, дизайном Liquid Glass и максимальной кастомизацией в стиле exteraGram.</b>
</p>

---

## 🌟 Ключевые особенности

### 🦀 1. Высокопроизводительное ядро на Rust (`extera-core`)
- Нативная библиотека `libextera_core.so` (архитектуры `arm64-v8a`, `armeabi-v7a`, `x86_64`).
- Перехват сетевых пакетов MTProto на уровне криптографического движка Rust.
- **Ghost Mode Engine**:
  - Полное скрытие статуса прочтения сообщений (блокировка `messages.readHistory`).
  - Скрытие индикатора набора текста («Печатает...»).
  - Скрытие онлайн-статуса («В сети»).
  - Ghost Stream (синхронизация без фиксации времени активности).
- **Anti-Delete Cache**: сохранение сообщений, удалённых собеседником, в локальном безопасном хранилище.

### 🫧 2. Liquid Glass & Material Design 3
- Жидкое стекло с динамическим размытием фона (`RenderEffect` / аппаратные шейдеры).
- Настоящая зеркальная фаска и подсветка граней (Specular Sheen & Border Glow).
- Поддержка динамической палитры **Material You (Monet)** из обоев смартфона.
- Ручной выбор акцентных палитр (Ocean Blue, Emerald, Amethyst, Sunset Amber, Rose).

### 🛠️ 3. Глубокая кастомизация интерфейса
- Регулировка радиуса размытия стекла (0–40 dp) и прозрачности.
- Скругление углов сообщений от 4 до 32 dp.
- Отображение ID пользователей и чатов.
- Отображение точного времени редактирования до секунд.
- Пересылка сообщений без цитирования оригинального автора.

## 🏗️ Автоматическая сборка APK на GitHub

Проект оснащён CI/CD пайплайном в GitHub Actions:
- Кросс-компиляция крейта Rust под Android NDK r26b через `cargo-ndk`.
- Сборка нативного Android APK через Gradle.
- Автоматическая публикация релиза с готовым `.apk` файлом для установки.

## 📱 Скриншоты структуры

- **Чаты**: Стеклянная плавающая панель, бейджи непрочитанных, статус ядра Rust.
- **Диалог**: Кастомные пузыри, бейдж `🗑️ Удалено собеседником`, отображение ID.
- **Настройки**: Хаб кастомизации с переключателями Ghost-режима, ползунками Liquid Glass и палитрами Monet.
