## 🌟 Возможности ExteraLight

- **🎨 Чистый Material Design 3 (Material You)**:
  - Автоматическая адаптация палитры (Monet) под обои вашего Android.
  - Никаких ресурсоёмких шейдеров размытия («ликвид гласа») — только нативные M3-поверхности, гладкие анимации и максимальная скорость.
  - Кастомные Monet акценты: Emerald, Amethyst, Amber, Rose, Nordic Cyan.

- **🧩 Плагины и фичи в стиле exteraGram**:
  - 👻 **Ghost Mode (Режим невидимки)**: читайте сообщения так, чтобы собеседник и сервер не знали об этом. Статус «Печатает...» полностью отключен.
  - 🛡️ **Anti-Delete**: сообщения, удалённые собеседником, остаются в чате с меткой `🗑️ Удалено собеседником`.
  - 🏷️ **ID Inspector**: отображение реальных Telegram ID в сообщениях и карточках контактов с копированием в один тап.
  - 🌐 **Datacenter Locator**: отображение реального датацентра Telegram (DC 1–5: Miami, Amsterdam, Singapore) в профилях.
  - ⏱️ **Точное время**: вывод времени редактирования до секунд.
  - ↩️ **Пересылка без цитирования**: отправка сообщений без указания оригинального автора.

- **🥚 Пасхалки (Easter Eggs)**:
  - Нажмите 5 раз на номер версии в настройках для активации скрытого **ExteraLight God Mode**!
